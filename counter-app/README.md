# create-a-counter-app

## Short Description
A simple counter application built using React, Babel, Webpack, and Jest for testing.

## Tech Stack
- **React**: A JavaScript library for building user interfaces.
- **Babel**: A toolchain that converts modern JavaScript into a backwards-compatible version of JavaScript.
- **Webpack**: A module bundler that helps manage the project's assets and dependencies.
- **Jest**: A JavaScript testing framework used to test React components.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/create-a-counter-app.git
   ```

2. Navigate to the project directory:
   ```bash
   cd create-a-counter-app
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

## Usage
1. Start the development server:
   ```bash
   npm start
   ```

2. Open your browser and go to `http://localhost:3000` to see the counter app in action.

## Project Structure

- **`README.md`**: This file.
- **`package.json`**: Contains project configuration, including dependencies and scripts.
- **`requirements.txt`**: Not applicable for JavaScript projects.
- **`src/index.html`**: Basic HTML structure for the application.
- **`src/App.js`**: Main component of the application, which includes the counter logic.
- **`src/Counter.js`**: Logic for managing the counter state.
- **`src/index.css`**: Basic styling for the application.
- **`tests/App.test.js`**: Unit tests for the `App` component.

## Running Tests
1. Run all tests:
   ```bash
   npm test
   ```

2. To run a specific test file, use:
   ```bash
   npm test <filename>.test.js
   ```
